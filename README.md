This is a Marvel inspired student event landing page called Campus Assemble. It presents a GeeksForGeeks student event as a superhero “mission,” where students can:

Explore event information,
Choose a hero and receive a project prompt,
View event highlights and schedule,
Edit page text directly in the browser.

Resources and technologies used :

HTML5 for page structure and content,
CSS3 for layout, colors, animations, responsive design, overlays, and visual effects,
Vanilla JavaScript for interactions and dynamic content,
Google Fonts,
Barlow Condensed,
Lucide Icons through the CDN.

The registration form is currently a front-end demo.
